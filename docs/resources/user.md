# goalert_user (Resource)

Manages a human operator user account in GoAlert.

## Example Usage

```terraform
resource "goalert_user" "lead" {
  name     = "Jane Operator"
  email    = "jane@example.com"
  role     = "admin"
  username = "jane"
  password = var.initial_password
}
```

## Schema

### Required

- `email` (String) The user's email address.
- `name` (String) The full name of the user.
- `username` (String) The login username for basic authentication. Cannot be modified after creation.

### Optional

- `password` (String, Sensitive) Initial password for basic authentication. Cannot be modified after creation without recreation.
- `role` (String) User permission role (`user` or `admin`). Defaults to `user`.

### Read-Only

- `id` (String) The unique identifier of the user generated by GoAlert.

## Import

Users can be imported using their UUID or compound `<user_id>/<username>` (recommended to populate the required `username` attribute into Terraform state):

```shell
terraform import goalert_user.lead 8541866e-eba1-4d6a-b905-3f2fe2da2c02/jane

# Or with standalone UUID:
terraform import goalert_user.lead 8541866e-eba1-4d6a-b905-3f2fe2da2c02
```
