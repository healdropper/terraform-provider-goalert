# v0.0.3: ingress and integration keys

Owner: healdropper. Recorded: 2026-09-26.
Status: Accepted planning direction. Ingress increment (`goalert_integration_key`
resource for Grafana alert reception on managed GoAlert services).
[GitHub milestone](https://github.com/healdropper/terraform-provider-goalert/milestone/3)
and [private delivery board](https://github.com/users/healdropper/projects/1).
This milestone is not a release or a production version selection.

## Recorded owner decisions

- Implement integration keys on GoAlert services to allow Grafana to send alerts directly into GoAlert.
- Type `grafana` is the priority target; generic webhooks remain an option.
- Telegram destination is established: bot `@ExampleAlertBot` and channel `Downstream Alerts`.
- Consumer integration in `downstream-consumer` will follow provider readiness to connect the end-to-end chain.

## Planning envelope

Proposed outcome: declare a GoAlert integration key resource attached to a managed
service, exposing the webhook URL/token for alert reception. Prove delivery from
synthetic Grafana alerts.

Reference behavior: [AD-02, AD-03 and AD-07](../specs/alert-delivery.md).
Preserve [SVC-01 through SVC-08](../specs/goalert-service.md) and escalation policies.
