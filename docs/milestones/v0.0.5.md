# v0.0.5: user identity, contact methods, and notification rules

Owner: healdropper. Recorded: 2026-09-27.
Status: Planned and tracked under [GitHub milestone 5](https://github.com/healdropper/terraform-provider-goalert/milestone/5)
and [Sprint 4](../sprints/sprint-4.md).

## Recorded owner decisions

- Implement human operator identity management via `goalert_user` (name, email, role).
- Implement user contact methods via `goalert_user_contact_method` (voice, SMS, email, webhook) supporting disabled state and value formatting.
- Implement user-level notification rules via `goalert_user_notification_rule` mapping delays to contact methods.
- Provide data source `data.goalert_user` for querying operators by ID or exact email/name.

## Planning envelope

Proposed outcomes:
1. Declare users with specified roles (`user`, `admin`).
2. Declare contact methods attached to users.
3. Declare escalation notification rules with configurable minute delays attached to contact methods.
4. Query existing user identity records via data source.
