# goalert_user_notification_rule resource specification

Authority: [Milestone v0.0.5](../milestones/v0.0.5.md), Gate V005-SPEC, [Issue #39](https://github.com/healdropper/terraform-provider-goalert/issues/39).

## 1. Resource identity
- Resource type: `goalert_user_notification_rule`
- Managed entity: Personal escalation notification rule mapping an elapsed delay to a user contact method.

## 2. Schema attributes

| Attribute | Type | Requirement | Mutability | Description |
| --- | --- | --- | --- | --- |
| `id` | String (UUID) | Computed | Read-only | Unique identifier generated by GoAlert. |
| `user_id` | String (UUID) | Required | RequiresReplace | Target user ID. |
| `contact_method_id` | String (UUID) | Required | RequiresReplace | Target contact method ID to alert. |
| `delay_minutes` | Int64 | Optional (Default: `0`) | RequiresReplace | Delay in minutes from alert trigger before notifying. Must be non-negative. |

## 3. Plan modifications and lifecycle rules
- All attributes are immutable (`RequiresReplace: true`) because GoAlert does not provide an `updateUserNotificationRule` mutation. Modifying `delay_minutes` or `contact_method_id` safely recreates the rule.

## 4. Import syntax
- Compound ID format: `<user_id>/<rule_id>`.
  ```shell
  terraform import goalert_user_notification_rule.example 8541866e-eba1-4d6a-b905-3f2fe2da2c02/0fac4581-8ca1-48de-8daf-85f7ae9e2284
  ```
