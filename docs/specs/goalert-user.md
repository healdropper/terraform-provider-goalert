# goalert_user resource specification

Authority: [Milestone v0.0.5](../milestones/v0.0.5.md), Gate V005-SPEC, [Issue #39](https://github.com/healdropper/terraform-provider-goalert/issues/39).

## 1. Resource identity
- Resource type: `goalert_user`
- Managed entity: User operator account in GoAlert.

## 2. Schema attributes

| Attribute | Type | Requirement | Mutability | Description |
| --- | --- | --- | --- | --- |
| `id` | String (UUID) | Computed | Read-only | Unique identifier generated by GoAlert. |
| `name` | String | Required | In-place | Full name of the operator. |
| `email` | String | Required | In-place | Email address of the operator. |
| `role` | String | Optional (Default: `"user"`) | In-place | Role in GoAlert: `"user"` or `"admin"`. |
| `username` | String | Required | RequiresReplace | Basic auth login username. |
| `password` | String | Optional (Sensitive) | RequiresReplace | Initial password for the user. Set once at creation. |

## 3. Plan modifications and lifecycle rules
- `username`: Modifying forces recreation of the user resource (`RequiresReplace: true`).
- `password`: Marked `Sensitive: true`. Modifying forces recreation (`RequiresReplace: true`).
- `name`, `email`, `role`: Mutated in-place via `updateUser(input: {id, name, email, role})`.

## 4. Import syntax
- Standard UUID or compound `<user_id>/<username>` import:
  ```shell
  terraform import goalert_user.example 8541866e-eba1-4d6a-b905-3f2fe2da2c02/jane
  # Or standalone UUID:
  terraform import goalert_user.example 8541866e-eba1-4d6a-b905-3f2fe2da2c02
  ```
  Note: Since password cannot be read from the GoAlert API, imported state sets password to null. Supplying `<user_id>/<username>` populates `username` into state to avoid replacement plans.
