# goalert_user_contact_method resource specification

Authority: [Milestone v0.0.5](../milestones/v0.0.5.md), Gate V005-SPEC, [Issue #39](https://github.com/healdropper/terraform-provider-goalert/issues/39).

## 1. Resource identity
- Resource type: `goalert_user_contact_method`
- Managed entity: Communication channel attached to a user operator account in GoAlert.

## 2. Schema attributes

| Attribute | Type | Requirement | Mutability | Description |
| --- | --- | --- | --- | --- |
| `id` | String (UUID) | Computed | Read-only | Unique identifier generated by GoAlert. |
| `user_id` | String (UUID) | Required | RequiresReplace | Target user ID to which this contact method belongs. |
| `name` | String | Required | In-place | Human-friendly label (e.g. "Work Email", "Pager SMS"). |
| `type` | String | Required | RequiresReplace | Type of contact method: `"SMS"`, `"VOICE"`, `"EMAIL"`, `"WEBHOOK"`, or `"SLACK_DM"`. |
| `value` | String | Required | In-place | Value (e.g. E.164 phone `+15555550199`, email address, or webhook URL). |
| `disabled` | Boolean | Computed | Read-only | Current operational status of the channel. |

## 3. Plan modifications and lifecycle rules
- `user_id`, `type`: Invariant. Modifying forces replacement (`RequiresReplace: true`).
- `name`, `value`: Mutated in-place via `updateUserContactMethod(input: {id, name, value})`.

## 4. Import syntax
- Compound ID format: `<user_id>/<contact_method_id>` or standalone `<contact_method_id>`.
  ```shell
  terraform import goalert_user_contact_method.example 8541866e-eba1-4d6a-b905-3f2fe2da2c02/ca7f2aff-8ab4-40f5-bfe4-45b291fde9ad
  ```
